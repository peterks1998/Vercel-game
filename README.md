# 2048

A clean, minimal implementation of the classic 2048 puzzle game — pure HTML, CSS, and JavaScript with no build step or dependencies.

## Play

Use the arrow keys (or swipe on touch devices) to slide tiles. Matching tiles merge into one with double the value. Reach **2048** to win, keep playing to go higher.

Your best score is saved locally in your browser.

## Development

This is a static site — just open `index.html` in a browser, or serve the folder with any static file server:

```bash
npx serve .
```

## Deployment

Deployed on [Vercel](https://vercel.com) as a static site. Every push to the main branch redeploys automatically — no build configuration required.
